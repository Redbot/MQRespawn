# /respawntimer

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/respawntimer [ui]
/respawntimer [slack] [slack in pixels]
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
UI for tracking live respawn of static NPC locations.
<!--cmd-desc-end-->

## Options

`/respawntimer ui`
:   Toggles UI to show

`/respawntimer slack 10`
:   Sets spawn location to a slack distance of 10 pixles (respawn is sometimes not 100% exact)
